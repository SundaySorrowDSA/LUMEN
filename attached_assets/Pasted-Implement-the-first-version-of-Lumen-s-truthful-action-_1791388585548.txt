Conservative matching

Do not mark an action verified merely because any tool ran.

A verified action must semantically correspond to the successful operation.

Examples:

* successful calendar retrieval can verify actions such as checking/looking at the schedule or calendar
* successful calculation can verify calculating, working out, or running the numbers
* a successfully created reminder can verify setting/creating that reminder
* a successfully cancelled reminder can verify cancelling/removing that reminder
* not-found or ambiguous reminder results must not verify a claimed successful cancellation or creation
* successful web search can verify searching/checking/looking something up online
* successful photo analysis can verify examining/looking at/analyzing the attached photo
* completed OpenAI consultation can verify asking/consulting OpenAI or Oracle
* successful generated-image delivery can verify generating/showing/sending the generated image

Do not allow tool evidence to verify unrelated embodied roleplay actions such as touching, kissing, leaning closer, smiling, walking, sitting, etc.

Prefer false negatives over false positives. If the action wording cannot confidently be associated with the successful tool operation, leave it unverified gray.
